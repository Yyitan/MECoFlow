# Contributing

Contributions are welcome.

Please use the following format when adding a paper:

```md
| Year | Venue | Title | Paper | Code | Setting | Keywords |
|---|---|---|---|---|---|---|
| 2026 | CVPR | Paper Title | [paper](https://example.com) | [code](https://github.com/example/repo) | CZSL | keyword1, keyword2 |
```

Suggested settings:

- CZSL
- OV-CZSL
- VLM-based CZSL
- Generalized CZSL
- Open-world CZSL
- Survey

Please keep paper titles in title case when possible, and use `-` if the code is not available.
