# CAMS-ADR 文献与创新边界审计

更新时间：2026-08-24

## 1. 阅读范围与结论

本轮对 `E:\lyt\研1\组合零样本\论文` 做了去重后的方法级审计。目录约 60 个文件，包含重复版本、综述、传统 CZSL、CLIP-CZSL、生成式 CZSL、OV-CZSL、测试时适配，以及少量偏离当前任务的扩散分类、CIR 和盲超分论文。当前与 CAMS-ADR/SLER 最直接相关的论文已经核对摘要、引言、方法主干与关键消融；非核心论文保留为第二层检索材料，并不宣称已经逐页精读全部文件。

核心判断：**“多分支 + 潜在单元 + 动态路由 + 多原型/多专家”本身不足以形成高水平论文的独立创新。** CAMS 已有潜在单元和多空间分支；Troika 已有三路径和实例条件跨模态牵引；EVA 已有动态专家路由与语义变体选择；ClusPro/LGPRO 已有多原型；CPF 与 PRPC 已分别覆盖条件依赖和双向纠错。可保留的创新边界必须落在：

1. 候选组合级而非输入 token 级的结构化证据推断；
2. 属性、对象、组合后验之间的全局一致性约束，而非三个独立分支简单相加；
3. 冻结基模型下的稳定残差校准，并有跨种子、跨数据集收益；
4. 与 EVA 的 MoE 路由、Troika 的视觉牵引、CPF 的单向条件建模做明确机制消融。

该选择也与目录中 CZSL Survey 的研究空白一致：综述把属性上下文化、开放世界中大规模且不可行的标签空间、鲁棒而无需显式硬 feasibility 计算的目标，以及高效可扩展架构列为主要开放问题。SPR 的候选后验协调可以同时落在“上下文化 + 不可行组合 + 轻量推理”交叉处，但仍需用结果证明，而不能只凭叙事成立。

## 2. 核心论文逐篇对照

| 工作 | 核心机制 | 与当前方案的重合 | 对创新设计的约束 |
|---|---|---|---|
| CAMS (2025) | 高层视觉块经 Gated Cross-Attention 写入潜在单元，再在属性/对象/组合多空间解耦 | 我们直接建立在其潜在单元与三分支上 | 不能把“latent units、多空间、门控交叉注意力”再作为新贡献 |
| Troika (CVPR 2024) | 属性/对象/组合三路径；Cross-Modal Traction 用当前视觉内容拉动文本原型 | 都是三分支且包含实例条件的跨模态调整 | 仅做三分支重加权或图文条件融合不新；需强调候选集合上的联合约束 |
| ClusPro (ICLR 2025) | 每个 primitive 多个视觉原型，在线聚类、原型对比与去相关 | 都试图表达 primitive 的上下文多义性 | “一个概念多个 latent/prototype”不新 |
| LGPRO (2026 workshop) | LLM 描述初始化多原型、语义锚定、自适应原型数 | 与语义 latent、多样性建模高度接近 | 不能把文本语义 latent 或自适应槽位单独作为主创新 |
| EVA (ICLR 2026) | 图文编码器内 MoE adapter；token 动态分配；从专家变体中选与 primitive 最匹配者 | 与动态路由、语义变体选择最接近 | 这是当前最大撞车点；必须证明不是普通 MoE/Top-k variant selection |
| SAM (CVPR 2026) | 文本到视觉 patch 的稀疏对齐、VAC 凝聚、动态视觉记忆库 | 都强调选择有用证据、抑制冗余 | 若改做 patch 稀疏选择或记忆库，会直接进入其覆盖范围 |
| Visual Proxy Learning (ICCV 2025) | 文本引导的视觉类别代理；文本原型与视觉代理联合学习和融合预测 | 同样用辅助表示修正跨模态分类 | 若仅增加视觉中心/代理和分数融合，创新不足 |
| MMPR/RAPR (AAAI 2024, IJCV 2026) | 视觉属性/对象与文本属性/对象四个数据库，检索相关 primitive 知识增强输入 | 与“证据库/latent memory”概念相近 | 显式外部检索或静态记忆库不是空白点 |
| CPF (ICCV 2025) | 文本增强对象学习，再以对象引导属性学习，显式建模条件概率 | 与 candidate/context-conditioned primitive 相关 | 单向 `p(o|x)p(a|o,x)` 已被覆盖；需要双边/全局后验一致性 |
| PRPC (2026) | MLLM 的对象→属性→对象→属性双向纠错，CoT + GRPO | 与反事实重组、互相校正相关 | “双向 primitive correction”作为一般概念已出现；轻量判别式方法需有不同数学落点 |
| I2CD (AAAI 2026) | 可逆网络的 disentangle-compose-disentangle；替换 primitive 生成反事实并保持未干预因素不变 | 与 counterfactual recomposition/route consistency 重合 | 不能泛称“反事实重组”；需限定为后验或路由空间中的结构约束并做对照 |
| EBCD (2025/2026) | 能量模型解耦，像素空间反事实生成和因果干预 | 与因果稳定性叙述相邻 | 无像素生成/严格因果识别时不应把方法包装成“因果” |
| FlowComposer (CVPR 2026) | 属性流和对象流匹配；Composer 显式合成速度场；利用泄漏特征做增强 | 都追求显式组合与残余纠缠利用 | 不能只说“显式在嵌入空间组合”；需与流式生成路线区分 |
| LOGICZSL (CVPR 2025) | LLM 生成关系知识，转成一阶模糊逻辑损失，约束层级/相似/上下文 | 都可利用类别关系结构 | 若加入语义图或逻辑规则，需超越其三类关系约束 |
| H2EM (2026) | 双曲空间承载语义层级与 primitive-composition 概念层级；蕴含锥与难负样本 | 都关注组合结构 | 层级几何是独立成熟路线，不适合作为 SLER 的轻量补丁叙事 |
| SPA (2026) | 保持 seen primitive 的局部结构，推理时把 unseen primitive 对齐到相似 seen 结构 | 与冻结锚点、结构保持相邻 | 若强调“保持 CLIP 几何/冻结锚点”，需限定普通 CZSL 稳定微调而非 OV-CZSL 概念迁移 |
| DIFFCZSL (2026) | 用扩散中间表示正则化 CLIP 图文嵌入，推理零额外成本 | 与外部生成先验不同 | 可作为后续正交增强，但不是当前轻量结构推断主线 |

## 3. 对现有 SLER 的审计

### 可保留部分

- 冻结 CAMS/Affinity 基模型，仅训练约 0.295M 参数的稳定残差适配器，能隔离“新增模块收益”和“基模型漂移”。
- 路由是**候选属性-对象组合条件**下对 CAMS latent evidence 的读取，而非 EVA 的编码器 token→expert 路由。
- 验证集分支消融显示对象路由有负迁移，属性+组合路由优于三分支全开，为“非对称证据可靠性”提供了实证线索。

### 当前不足

- 三种子测试平均提升仍小，开放世界 HM 还有下降，达不到论文主结果要求。
- 当前路由本质仍容易被审稿人归类为 contextual variant selection，与 EVA/Troika 的差异不够强。
- 反事实 route loss 在稳定版本中未发挥作用，不能作为已被验证的贡献。
- 只在 UT-Zappos 上有效远远不够，至少需要 MIT-States、UT-Zappos、C-GQA 三数据集闭集/开集结果。

## 4. 下一条更稳的创新主线

建议把下一阶段从“继续堆路由器”转为 **Structured Posterior Reconciliation (SPR，结构化后验协调)**：

1. 将 CAMS 的组合分支得分组织成属性×对象候选矩阵；
2. 从属性、对象分支得到两个 primitive 后验边缘；
3. 对组合后验做带基模型锚定的 KL 投影，使其行/列边缘与 primitive 后验协调；
4. 用熵或分支分歧自适应控制约束强度，避免错误 primitive 分支强行污染组合分支；
5. 对不可行组合加入 feasibility mask/soft prior；
6. 训练时可增加 leave-one-composition-out 的结构校准，推理时只做少量 Sinkhorn/镜像下降迭代。

这一路线的主要区分：EVA 在专家变体中选表示，Troika 调整文本表示，CPF 做对象到属性的单向条件学习，PRPC 用 MLLM 做离散步骤纠错；SPR 则把全部候选组合视为一个耦合后验，对属性、对象、组合三个预测空间做全局概率协调。它同时解释了当前“对象路由有害”的观察：低可靠性的对象后验应被不确定性门控，而不是与其他分支等权注入。

## 5. 论文级验证门槛

- 至少 3 个数据集、闭集和开集、3 个种子；报告均值与标准差。
- 与原 CAMS、Affinity-base、SLER、Troika式固定融合、EVA式 Top-k variant 选择、CPF式单向条件校正对照。
- 主指标目标：三数据集多数设置 AUC/HM 稳定正增益；不能以单个种子或只提升 AUC、显著牺牲 HM 作为成功。
- 必须包含：分支可靠性、校准误差、seen/unseen bias、投影前后边缘一致性、时间/参数开销。
- 任何超参数和分支选择只基于 validation；test 只做最终一次统一评估。

## 6. 生成式主线复核与 FlowComposer 精确边界（2026-08-24）

SPR 已被冻结三种子测试否决：验证平均正增益没有迁移到测试，不能继续作为
主线。此后对生成式相关论文的方法页与关键消融做了第二轮核查，得到以下更
严格的边界：

- FlowComposer 已包含 rectified flow、预测端点的对比分类损失、属性/对象原语
  流、速度 Composer、泄漏引导增强，以及同参数 endpoint-residual predictor
  对照。因此“首次把 flow matching 用于 CZSL”“flow 优于同参数 MLP”“端点
  对比约束”都不能作为 MERF 的创新权利要求。
- FlowComposer 的传输方向是视觉特征到文本端点，并把跨分支泄漏当作可复用
  特权信号；MERF 的方向是从加性组合中心附近的最大熵随机源生成视觉类支持，
  并用分布替换主动删除 seen-pair 残差身份。两者对泄漏的处理目标相反。
- 传统生成式 CZSL（包括基于生成模型识别未见属性-对象、learnable primitive
  disparity transfer、DeFA）会合成未见特征或重组 primitive，但没有同时定义
  “固定二阶矩下最大熵残差源 + seen-pair 身份探针 + 条件连续运输”的机制。
- ADiVA/GDC 等生成式 ZSL 使用高斯噪声或生成分类，但不针对组合残差中的
  seen-pair 身份泄漏，也不使用属性-对象 ANOVA 源中心。单说“Gaussian feature
  generation”不新，必须保留匿名化的约束、探针和因果消融。
- 扩散分类中的 noise optimization 与数据稀缺分类中的 inversion interpolation
  都说明噪声选择会影响预测，但研究对象是预训练扩散模型的输入噪声，不是
  CZSL 视觉残差身份。它们要求我们报告噪声尺度/分布消融，但不覆盖 MERF。

由此，论文可主张的最小创新单元是：

1. 证明经验组合残差可识别 seen pair，而最大熵矩匹配源把识别率降到机会水平；
2. 从可组合 ANOVA 中心与匿名随机残差出发，学习到真实视觉分布的条件运输；
3. 用零随机性、直接端点、一步流、经验/对角/各向同性源做匹配消融；
4. 验证门控在无可靠收益的数据集自动停用，避免测试后选择。

新的正交扩展是 **reverse primitive flow generation**：对 FlowComposer 冻结的
视觉→文本原语速度场做反向 ODE，从带切空间最大熵噪声的组合文本端生成未见
视觉原型。1-epoch UT smoke checkpoint 的固定缓存 validation-only 配对结果为：
noise=0 相对文本原型 +0.605 AUC/+0.910 HM；noise=0.05 的三个生成随机种子为
+0.770±0.015 AUC/+0.757±0.000 HM，三次全部双指标为正。无 gate 对照虽然
AUC 约 +0.37，但 HM 约 -0.35，支持 Stage-2 原语组合门控对平衡迁移有实际
作用。noise=0.4 时 AUC 收益消失，说明最大熵扰动必须局限在语义端点的局部
切空间。生成三种子只排除了随机噪声抽样偶然，不能替代独立训练 seed。

缓存审计发现官方 train transform 的随机 flip/perspective/rotation 会改变
seen 类中心，使跨缓存绝对指标漂移；因此旧结果只保留同缓存配对差值。脚本已
强制用 deterministic validation transform 提取 train evaluation features，且把
该设置写入 cache provenance。完整 checkpoint 必须重建修正后的确定性缓存。

与 1-epoch 官方 logits 的 AUC 优先融合可再提高约 +0.57 AUC，但 HM 下降约
0.75，且最优权重落在搜索边界，因此该融合结果不升级为证据。当前只保留
“冻结正向原语流的反向生成用途”这一正交假设；必须在完整 Stage-1/2、独立
随机种子和最终一次 test 上复现，才能作为论文贡献。它不能被表述成首次
Flow-CZSL，而应表述为从判别式视觉→文本流中抽取生成式反向类支持。

## 7. DIFFCZSL 精确边界与对 MERF 的约束（2026-08-24）

对 `arxiv2026-DIFFCZSL Compositional Zero-Shot Learning Regularized.pdf` 的方法、
主表、消融、效率与附录做了逐页复核。DIFFCZSL 不生成未见类视觉特征：它用
Stable Diffusion 2.1 上的 CleanDIFT 从每张真实训练图像提取无噪中间特征，做
全局平均池化，再由两个两层 ReLU MLP 分别投影到 CLIP 视觉空间与组合文本
空间。训练时用两个双向 batch contrastive loss 对齐扩散先验与基线图像/文本
表示；扩散分支推理时移除。因此它覆盖的是“生成模型表征作为训练期双空间
正则器”，不是“从匿名随机源到未见组合视觉分布的条件运输”。

关键结果与控制项如下：

- DIFF-CAMS 在 UT-Zappos 闭集把 CAMS 的 HM/AUC 从 `56.6/45.0` 提到
  `57.9/46.1`，开集从 `50.8/35.7` 提到 `52.6/38.1`；MIT-States 闭集
  `40.3/23.4→40.7/24.0`，C-GQA 闭集 `33.7/15.8→34.2/16.2`。
- 主消融基于 Troika：图像侧和文本侧蒸馏各自有效，联合最好；SD2.1 优于
  SD1.5；CleanDIFT 无噪特征优于带噪 SD2.1 特征；DINOv3 教师远弱于扩散
  教师。这说明收益不能简单归因为“增加一个大预训练教师”。
- 论文只对 DIFF-Troika 报告三训练种子稳定性，而不是 DIFF-CAMS。UT-Zappos
  三种子均值为 HM `57.7±0.2`、AUC `45.4±0.8`，相应 Troika 基线为
  `54.6±0.5/41.7±0.7`。主表中的单次 DIFF-Troika AUC `46.2` 不能和
  三种子均值混写。
- DIFF-CAMS 在 UT-Zappos 使用 15 epoch、`λimg=0.5`、`λtxt=0.1`、
  diffusion layer 6、1280 维外部特征和 1536 隐层；每 epoch 从 6m36s 增至
  7m41s，增加 17.7M 训练参数，但无推理开销。
- 关系分析显示 diffusion 特征中属性位移跨对象的一致性均值高于 CLIP
  (`0.2012` 对 `0.1887`)。这为“生成式表征包含可迁移组合关系”提供依据，
  但不是未见组合类条件分布建模的证据。

由此收紧新颖性表述：不能声称首次把扩散/生成先验用于 CZSL、首次把生成模型
知识蒸馏到 CLIP、或首次实现训练期生成监督且推理零开销。MERF 的可区分贡献
必须保持为：在固定矩约束下构造匿名最大熵组合残差源；用 seen-pair 身份探针
直接验证去身份化；学习从 ANOVA 可组合中心到真实视觉支持的条件连续运输；
最后用生成的未见组合视觉支持训练/校准分类器。其输入不是 CleanDIFT 的真实
图像教师特征，也没有 Stable Diffusion 依赖，且当前分类器融合有额外推理开销，
不能借用 DIFFCZSL 的“零推理开销”叙事。

实验层面，DIFF-CAMS 是必须正面讨论的同期强基线。若代码或预提取 CleanDIFT
特征可获得，应在同一 CAMS 配置上复现；若无法获得，也必须按论文协议清楚列出
其公开数值与不同评估协议，禁止把我们不同 checkpoint、不同缓存或不同种子
协议的绝对指标直接横比。更有说服力的组合方式应是正交性验证：DIFFCZSL
改善真实训练样本的表示几何，MERF 补足未见组合的视觉分布支持；只有在冻结
验证协议下二者可叠加且跨训练种子稳定，才能把“互补”升级为论文结论。
